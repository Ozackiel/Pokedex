# Pokedex com .NET MAUI

Projeto Inicial de carreira visando observar e praticar fundamentos da programação através de uma Pokedex consumindo serviços de uma API, vendo e aplicando estruturas de código do JavaScript, HTML e CSS.

## Funcionalidades

- [ ] Listar Pokémons
- [ ] Buscar Pokémons
- [ ] Detalhes do Pokémon
- [ ] Filtros por tipo
- [ ] Ordenação
- [ ] Dark Mode


## Tech Stack

- .NET MAUI
- C#
- HTML
- CSS
- JavaScript
